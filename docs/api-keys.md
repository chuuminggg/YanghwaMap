# 운전 탭 API 키 발급 가이드

운전 탭(`/drive`)은 우리 DB가 아니라 외부 기관 API를 그때그때 부른다. 기관마다 인증키가 따로라
**키가 없는 탭만 안내 문구로 끝나고 나머지 탭은 그대로 동작한다.** 필요한 것부터 하나씩 채우면 된다.

이 문서의 링크와 동작은 **2026-09-12에 직접 확인**했다. 기관 사이트는 개편이 잦으니
메뉴 이름이 다르면 아래 "무엇을 찾아야 하는가"를 기준으로 찾으면 된다.

---

## 한눈에

| 환경 변수 | 쓰는 탭 | 필수 | 발급처 | 승인 |
|---|---|:---:|---|---|
| `DATA_GO_KR_API_KEY` | 주차장, 충전소 | ✅ | [공공데이터포털](https://www.data.go.kr) | 즉시(자동승인) + 반영 대기 |
| `OPINET_API_KEY` | 주유소 | ✅ | [오피넷](https://www.opinet.co.kr/user/custapi/openApiInfo.do) | 담당자 검토 |
| `ITS_API_KEY` | 고속도로 CCTV | △ | [ITS 국가교통정보센터](https://www.its.go.kr/opendata/opendataList?service=cctv) | 즉시 |
| `EXDATA_API_KEY` | 고속도로 소통 | ✕ | [고속도로 공공데이터 포털](https://data.ex.co.kr/openapi/intro/introduce01) | 즉시 |
| `KAKAO_REST_API_KEY` | 주차장, 충전소 (좌표 → 시군구) | ✅ | [카카오 개발자센터](https://developers.kakao.com) | 즉시 |

- ✅ 없으면 그 탭이 `503` + 발급 안내로 끝난다
- △ 데모 키로도 뜨긴 하지만 **반경이 적용되지 않는다** (아래 ITS 항목 참고)
- ✕ 데모 키 `test` 로 충분하다. 쿼터가 모자랄 때만 발급받으면 된다
- **보조금 탭은 키가 필요 없다** (ev.or.kr 공개 자료)

`KAKAO_REST_API_KEY` 는 원래 화장실 좌표 채우기에만 쓰던 값인데, 운전 탭이 좌표를
시군구로 바꾸는 데도 쓴다. 이미 넣어 뒀다면 추가로 할 일은 없다.

## 1. DATA_GO_KR_API_KEY — 공공데이터포털

주차장·충전소 두 탭이 쓴다. **가장 헷갈리는 키라 여기만 자세히 적는다.**

### 발급

1. [www.data.go.kr](https://www.data.go.kr) 회원가입 후 로그인
2. 아래 **두 데이터셋을 각각** 찾아 `활용신청` 을 누른다
   - [전국주차장정보표준데이터 (15012896)](https://www.data.go.kr/data/15012896/standard.do) — `오픈 API` 탭에서 신청
   - [한국환경공단_전기자동차 충전소 정보 (15076352)](https://www.data.go.kr/data/15076352/openapi.do)
3. 활용목적은 자유 서술(개인 학습/토이 프로젝트 등)로 충분하다
4. `마이페이지 > 데이터활용 > Open API > 인증키 발급현황` 에서 키를 복사한다

### 함정 ①: 데이터셋마다 활용신청이 따로다

**키는 계정당 하나지만, 신청은 데이터셋마다 해야 한다.** 주차장만 신청하고 충전소 탭을 열면
같은 키인데도 거부당한다. 둘 다 자동승인이라 신청 즉시 승인은 되지만,
**실제로 호출이 통하기까지 수십 분에서 한 시간쯤 걸린다.** 승인 직후 안 되는 건 정상이다.

### 함정 ②: 일반 인증키가 두 종류다

발급현황 화면에 `Encoding` 과 `Decoding` 두 값이 나온다. 같은 키를 URL 인코딩한 것과 아닌 것이다.

```
Encoding : abc%2Bdef%2Fghi%3D%3D      ← % 가 섞여 있다
Decoding : abc+def/ghi==              ← + / = 가 그대로 보인다
```

이 앱은 **둘 중 아무거나 넣어도 되게** 처리해 뒀다(`api/_lib/datagokr.ts`가 한 번 풀었다 다시
인코딩한다). 굳이 고르자면 **Decoding 쪽을 권한다** — 눈으로 보고 잘못 복사했는지 알기 쉽다.

> 다만 두 값을 섞어 붙이거나 `%` 가 들어간 값을 잘못 자르면 디코딩 단계에서 터져
> `500` 이 난다. 복사는 한 칸 전체를 통째로 하는 게 안전하다.

### 함정 ③: 따옴표를 붙이지 말 것

`.env.local` 에서 `DATA_GO_KR_API_KEY="abc..."` 처럼 쓰면 따옴표까지 키가 된다.
`DATABASE_URL`·`APP_PASSWORD` 와 같은 규칙이다.

## 2. OPINET_API_KEY — 오피넷

주유소 탭이 쓴다.

1. [오피넷 오픈 API 안내](https://www.opinet.co.kr/user/custapi/openApiInfo.do) 에서 인증키를 신청한다
2. 공공데이터포털과 달리 **담당자 검토를 거친다.** 바로 나오지 않을 수 있다

### 확인이 까다로운 이유

**오피넷은 인증키가 거부돼도 오류를 주지 않고 빈 목록을 준다.** 그래서 서버가
"반경 안에 주유소가 없음"과 "키가 거부됨"을 구분할 수 없다. 화면에서도 두 가능성을 함께 안내한다.

> 반경을 5km로 넓혔는데도 계속 비어 있다면 반경 문제가 아니라 키 문제로 보는 편이 맞다.
> 서울·부산 도심 3km 안에 주유소가 한 곳도 없을 수는 없다.

## 3. ITS_API_KEY — 국가교통정보센터 (CCTV)

고속도로 탭의 CCTV 모드가 쓴다. **없어도 화면은 뜨지만 '내 주변'이 되지 않는다.**

1. [ITS 오픈데이터 > CCTV 정보](https://www.its.go.kr/opendata/opendataList?service=cctv) 에서 회원가입 후 `인증키 신청`
2. 발급은 즉시다

### 왜 데모 키로는 부족한가

공개 데모 키 `test` 는 **좌표 범위(`minX`/`maxX`/`minY`/`maxY`)를 통째로 무시하고
항상 같은 20건(수도권제1순환선)을 돌려준다.** 부산으로 조회해도, 제주로 조회해도 같은 응답이다
(2026-08-31 직접 확인).

그래서 데모 키일 때는 서버가 반경으로 자르지 않는다 — 자르면 목록이 늘 비어 고장처럼 보인다.
대신 화면에 `공개 데모 키라 반경이 적용되지 않습니다 — 전국 표본 20대` 라고 밝힌다.
`ITS_API_KEY` 를 넣으면 이 문구가 사라지고 실제 반경이 적용된다.

---

## 4. EXDATA_API_KEY — 한국도로공사 (소통)

고속도로 탭의 소통 모드가 쓴다. **데모 키 `test` 가 실제로 잘 동작하므로 보통은 넣지 않아도 된다.**
전국 8천여 개 검지기 실시간 자료가 그대로 온다.

쿼터가 모자라거나 데모 키가 회수되면
[고속도로 공공데이터 포털 > 인증키 발급 절차](https://data.ex.co.kr/openapi/intro/introduce01) 에서 발급받아 넣는다.

## 넣는 곳

### 로컬

`.env.local` 에 추가한다. 형식은 [.env.example](../.env.example) 을 그대로 따르면 된다.

```bash
DATA_GO_KR_API_KEY=
OPINET_API_KEY=
ITS_API_KEY=
EXDATA_API_KEY=
```

**`VITE_` 접두사를 붙이면 안 된다.** 붙이는 순간 빌드 결과물에 키가 그대로 들어가 공개된다.
이 키들은 전부 서버(`/api`)에서만 읽는다.

추가한 뒤 **dev 서버를 다시 띄워야 한다.** `vite.config.ts` 의 `SERVER_ENV_KEYS` 가
시작할 때 한 번만 읽는다.

### 배포 (Vercel)

프로젝트 > `Settings` > `Environment Variables` 에 같은 이름으로 넣는다.
**다음 배포부터 반영된다** — 값만 넣고 재배포하지 않으면 그대로다.

```bash
vercel env pull .env.local   # 반대로 배포 환경 값을 로컬로 내려받을 수도 있다
```

## 잘 들어갔는지 확인

dev 서버를 띄운 뒤 (`npm run dev`) 각 엔드포인트를 직접 불러 본다.
좌표는 합정역 기준이다.

```bash
# 키 없이도 200 이어야 정상
curl -s "http://localhost:5173/api/drive/highway?kind=traffic&limit=3"
curl -s "http://localhost:5173/api/drive/subsidy?vehicle=passenger"

# 키를 넣은 뒤 200 + 목록이 나와야 한다
curl -s "http://localhost:5173/api/drive/gas?lat=37.5495&lng=126.9137&radius=3000"
curl -s "http://localhost:5173/api/drive/parking?lat=37.5495&lng=126.9137&radius=1500"
curl -s "http://localhost:5173/api/drive/chargers?lat=37.5495&lng=126.9137&radius=2000"
```

기대 결과:

| 상태 | 응답 |
|---|---|
| 키 없음 | `503` + 어디서 발급받는지 적힌 메시지 |
| 키는 있으나 활용신청 미승인 | `502` + 활용신청 확인 안내 |
| 정상 | `200` + `items` 배열 |

## 오류 메시지별 대응

| 화면/응답에 보이는 것 | 원인 | 할 일 |
|---|---|---|
| `DATA_GO_KR_API_KEY가 설정되지 않았습니다` | 환경 변수 없음 | 키를 넣고 dev 서버 재시작 / Vercel 재배포 |
| `인증키가 등록되지 않았습니다` | 키 값이 틀림 | 발급현황에서 한 칸 통째로 다시 복사 (따옴표 금지) |
| `이 데이터셋에 대한 활용신청이 아직 승인되지 않았습니다` | 해당 데이터셋 신청 누락 또는 반영 전 | 데이터셋별로 신청했는지 확인, 승인 후 한 시간쯤 기다리기 |
| `오늘 사용할 수 있는 호출 횟수를 다 썼습니다` | 일일 쿼터 초과 | 내일 재시도 또는 포털에서 트래픽 증가 신청 |
| 주유소 목록이 계속 비어 있음 | 오피넷 키 거부 가능성 | 반경 5km로도 비면 키를 의심 (오피넷은 오류 대신 빈 목록을 준다) |
| `공개 데모 키라 반경이 적용되지 않습니다` | ITS 개인 키 없음 | `ITS_API_KEY` 발급 |
| `카카오 인증에 실패했습니다` | REST API 키 문제 | JavaScript 키가 아닌 **REST API 키**인지, 카카오맵/로컬 API 사용 설정이 켜져 있는지 확인 |
| `현재 위치의 행정구역을 찾지 못했습니다` | 국내 좌표가 아님 | 국내에서 조회하거나 위치 권한 확인 |

## 참고

- 서버가 `502`(기관 실패)와 `503`(우리 설정 문제)을 구분한다. `503`이면 우리가 고칠 수 있는 문제다
- 응답은 CDN에 잠깐 캐시된다(`Cache-Control`). 키를 막 넣었는데 그대로면 잠시 뒤 다시 보거나 쿼리를 바꿔 본다
- 각 기관 원본과 필드 의미는 [README](../README.md#운전) 의 운전 탭 표에 정리돼 있다
